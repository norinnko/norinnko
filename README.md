### 🚀 公開中のアプリ

| アプリ | 内容 |
|---|---|
| [もじばけもの図鑑](https://nori-hack.norinko.jp/) | 言葉を本物の文字化けにかけ、生まれた妖怪を AI が読み解く図鑑 |
| [AIおぴにおん](https://ai-hack.norinko.jp/) | カメラに映った顔を AI が見て、架空の「生体異常」をでたらめに診断 |
| [NoriNews](https://norinews.norinko.jp/norinews) | IT・セキュリティニュースを毎朝自動で集めて日本語で要約（[コード](https://github.com/norinnko/norinews)） |
| [CTF Tool DB](https://ctf-tool.norinko.jp/) | CTF でよく使うツール40種の早見表（[コード](https://github.com/norinnko/ctf-tool)） |
| 就活マネージャー | 選考・予定・ES を管理し、Google カレンダー連携と LINE 通知に対応（[コード](https://github.com/norinnko/shukatsu-manager)） |
